Decision: package approved as a structured **PRIMARY + SUPPORT** library.

## Baseline body target preserved
- balanced adult feminine curvy silhouette
- waist clearly defined but not extreme
- pelvis visible but without abrupt flare
- thighs with moderate healthy volume, not overly heavy
- torso length balanced against leg length
- bust rendered with more natural lower/side weight and ribcage connection rather than spherical upper fullness

## Physics QC
The accepted pose images are allowed to show pose-dependent changes such as compression, lateral spread, altered projection, and weight-bearing asymmetry. These are not canonical body changes.

## Explicit exclusion
A prior single quadruped/glamour candidate was rejected and is not in this package because it over-emphasized lumbar arch, waist narrowing and glute projection.

## Remaining limitation
The back view is usable for silhouette and rear proportion checking, but a future optional hair-tied back reference could expose scapular/spinal landmarks more clearly. This is not required to use v2.0.
