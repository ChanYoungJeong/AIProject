## 2. 설정

| 항목 | 값 |
|---|---|
| 모델 | Seedream 4.5 |
| 화면비 | 9:16 |
| 퀄리티 | high (가능하면) |
| 생성 방식 | Unlimited / 웹 플랜 (수동) |
| 시드 | 랜덤 (1차 시도) |

**왜 9:16인가**: 프롬프트가 원래 "4:5"라고 적혀있었지만, 실제로 잘 나왔던 과거 결과는 9:16 설정으로 생성된 것이었습니다. 얼굴+전신+다리가 한 프레임에 다 들어가야 하니 세로가 더 긴 9:16이 목적에 맞고, 이번엔 프롬프트 텍스트도 9:16으로 맞춰뒀습니다.

**퀄리티를 high로 권장하는 이유**: 이건 마스터라서, 나중에 만들 SNS용 사진 전부가 여기서 파생됩니다. 마스터 품질이 안 좋으면 그 결함이 이후 모든 결과물에 그대로 유전됩니다 — 한 번 잘 만드는 게 낫습니다.
