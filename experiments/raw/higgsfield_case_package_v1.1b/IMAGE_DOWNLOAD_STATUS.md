# IMAGE DOWNLOAD STATUS

The exact Higgsfield reference-image URLs and output-image URLs are preserved in each case.

I attempted to download the binary image files into this package, but this runtime blocks direct binary downloads from the Higgsfield/CloudFront URLs even though the Higgsfield connector can display and identify them.

To avoid silently substituting incorrect images, no different local project images were used as replacements.

Each case already contains the intended filenames and exact source URLs in `REFERENCE_URLS.txt`. The `references/` folders are created and ready for the binary files once those source images are available as local/uploaded files.
